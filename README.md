# 🩸 Smart Blood Ecosystem

AI-Powered Blood Donation, Inventory Management, Emergency Response & Healthcare Intelligence Platform.

---

## 🚀 Overview

Smart Blood Ecosystem is a full-stack MERN application designed to modernize blood bank operations through Artificial Intelligence, Analytics, Geospatial Intelligence, and Emergency Response Management.

The platform connects:

- Donors
- Hospitals
- Administrators
- Blood Inventory
- Emergency Requests

into a unified healthcare ecosystem.

## ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/HarshiniK29/SmartBloodEcosystem.git
```

Go to Project

```bash
cd SmartBloodEcosystem
```

Install Dependencies

```bash
npm install
```

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

---

## 🧪 Environment Variables

Create `.env` inside `/server`

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

## ▶ Running Application

Backend

```bash
cd server
npm run dev
```

Frontend

```bash
cd client
npm run dev
```
